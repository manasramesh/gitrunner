## 🎯 Enable GitHub Pages (2 Methods)

### Method 1: Using GitHub Actions (Recommended) ✅

**Already set up!** The workflow file is deployed.

**Steps:**
1. Go to: https://github.com/manasramesh/gitrunner
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select: **GitHub Actions**
4. Click **Save**
5. Wait 1-2 minutes for deployment

**That's it!** GitHub Actions will automatically deploy on every push.

### Method 2: Direct Branch Deploy (Alternative)

If you prefer simpler setup:

1. Go to: https://github.com/manasramesh/gitrunner/settings/pages
2. Under **Source**, select: **Deploy from a branch**
3. Choose **main** branch
4. Choose **/ (root)** folder
5. Click **Save**

## 📊 How This Works

### GitHub Pages Types:

| Type | Repository Name | URL | Your Setup |
|------|----------------|-----|------------|
| **User/Org Site** | `manasramesh.github.io` | `manasramesh.github.io` | Jekyll site ✓ |
| **Project Site** | Any other repo (e.g., `gitrunner`) | `manasramesh.github.io/gitrunner` | This game ✓ |

**Key Point**: Project sites use the **repo name** as the path!
